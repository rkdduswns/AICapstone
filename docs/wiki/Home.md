# ContextTrace

> **Windows 작업 로그 기반 개인 지식 출처 역추적 RAG 시스템**

ContextTrace는 Windows 환경에서 사용자의 작업 맥락을 자동으로 수집하고, 이를 로컬 지식 저장소에 축적한 뒤, 자연어 질의를 통해 과거에 열람한 정보의 **정확한 출처와 작업 맥락을 다시 찾을 수 있도록 지원하는 개인용 리서치 어시스턴트**입니다.

---

## 프로젝트 배경

자료 조사와 문서 작업을 수행하다 보면 다음과 같은 상황이 자주 발생합니다.

- 예전에 읽었던 내용은 기억나지만 어느 웹페이지였는지 기억나지 않음
- PDF 내용은 기억나지만 파일명을 찾기 어려움
- 브라우저 방문 기록만으로는 실제 열람한 내용을 기준으로 검색하기 어려움
- 브라우저, PDF 뷰어, Word, VS Code 등 여러 프로그램에서 확인한 자료를 한 번에 검색하기 어려움
- 북마크, 태그, 메모를 직접 남기지 않으면 작업 맥락이 사라짐

ContextTrace는 이러한 문제를 해결하기 위해 **Windows 전역의 작업 맥락을 수동 개입 없이 기록하고, 의미 기반 검색을 통해 과거 정보의 출처를 역추적**합니다.

---

## 핵심 목표

### 1. 별도 저장 동작 없는 자동 기록

사용자가 북마크나 태그를 직접 남기지 않아도 현재 활성화된 프로그램, 창 제목, URL, 파일 정보, 복사한 텍스트 등을 자동으로 기록합니다.

### 2. 프로그램을 넘나드는 통합 추적

웹 브라우저뿐 아니라 PDF, Word, VS Code 등 Windows에서 사용하는 다양한 프로그램의 작업 기록을 하나의 저장소에서 관리합니다.

### 3. 자연어 기반 출처 검색

사용자가 정확한 파일명이나 URL을 기억하지 못해도 다음과 같은 질문으로 자료를 찾을 수 있도록 합니다.

> 지난주 Chrome에서 봤던 B2B SaaS 수익 모델 관련 자료 찾아줘.

### 4. 실제 기록에 근거한 답변

답변은 가능한 경우 다음 출처 정보를 함께 제공합니다.

- 문서명 또는 페이지 제목
- URL 또는 파일 경로
- 사용 프로그램
- 열람 시간
- 관련 텍스트
- 관련 작업 세션

### 5. 로컬 우선 개인정보 보호

작업 로그와 원본 데이터는 기본적으로 사용자 PC 내부에 저장하며, 민감한 프로그램·사이트·텍스트는 저장 단계에서 제외합니다.

## 시스템 동작 흐름

```text
Windows 작업 활동
      ↓
작업 맥락 수집기
      ↓
개인정보 보호 필터
      ↓
맥락 전처리
      ↓
SQLite + 벡터 데이터베이스
      ↓
혼합 검색 엔진
      ↓
근거 기반 RAG
      ↓
답변 + 출처 + 열람 시간
```

## 핵심 차별점

### 기존 브라우저 기록과의 차이

브라우저 방문 기록은 웹 URL 중심으로 관리됩니다.

ContextTrace는 다음 작업 정보를 하나의 맥락으로 연결합니다.

```text
웹페이지
+
PDF
+
문서
+
IDE
+
클립보드
+
열람 시간
```

### 일반 RAG와의 차이

일반적인 RAG 시스템은 사용자가 직접 문서를 업로드하여 검색 지식 저장소를 만듭니다.

ContextTrace는 사용자가 실제로 작업하는 과정에서 발생한 기록을 자동으로 축적합니다.

```text
일반 RAG

문서 업로드
    ↓
벡터 데이터베이스
    ↓
질의응답
```

```text
ContextTrace

Windows 작업 활동
    ↓
자동 맥락 수집
    ↓
개인 지식 저장소
    ↓
출처 역추적
```
