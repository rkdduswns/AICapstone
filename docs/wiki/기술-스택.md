# 기술 스택

ContextTrace는 Windows 환경과 Python 기반의 빠른 개발을 중심으로 기술을 구성합니다.

---

## 전체 기술 구성

| 영역 | 기술 |
|---|---|
| 백엔드 | Python, FastAPI |
| Windows 연동 | pywin32, ctypes, psutil |
| 클립보드 | pyperclip, Windows Clipboard API |
| 브라우저 연동 | Chrome Extension API, JavaScript |
| 로컬 통신 | Native Messaging, WebSocket 또는 Local REST API |
| 문서 처리 | PyMuPDF, python-docx |
| 정형 데이터 저장 | SQLite |
| 벡터 저장 | ChromaDB 또는 FAISS |
| 임베딩 | Sentence Transformers 또는 OpenAI Embedding |
| RAG | LangChain 또는 LlamaIndex |
| LLM | OpenAI API 또는 로컬 LLM |
| 데스크톱 UI | PySide6 |

---

## 1. Python

프로젝트의 핵심 백엔드 및 Windows 수집 모듈을 구현하는 기본 언어입니다.

선정 이유:

- Windows API 연동이 쉬움
- AI / RAG 생태계가 풍부함
- SQLite, ChromaDB 연동이 간단함
- PDF / DOCX 처리 라이브러리가 다양함
- 빠른 프로토타이핑에 적합함

---

## 2. Windows 작업 정보 수집

### pywin32

Windows API를 Python에서 사용할 수 있도록 지원합니다.

활용 예:

- 활성 창 정보
- 창 제목
- Windows 메시지 처리
- 프로세스 연동

### ctypes

필요한 Windows API를 직접 호출할 때 사용합니다.

활용 대상 예:

```text
GetForegroundWindow()
GetWindowText()
GetWindowThreadProcessId()
```

### psutil

활성 창에서 얻은 프로세스 ID를 이용해 실행 프로그램 정보를 확인합니다.

활용 정보:

```text
프로세스명
실행 경로
PID
```

---

## 3. 클립보드 수집

### pyperclip

텍스트 기반 클립보드 데이터를 간단히 읽을 때 사용합니다.

초기 버전에서는 텍스트 클립보드만 지원하고 이미지나 파일 복사는 범위에서 제외합니다.

---

## 4. 브라우저 연동

### Chrome Extension API

Chrome 및 Chromium 기반 Edge의 현재 탭 정보를 가져오기 위해 사용합니다.

수집 정보:

```text
URL
페이지 제목
도메인
탭 식별 정보
```

### 로컬 통신 방식

브라우저 확장 프로그램과 Python 백엔드 간 통신은 다음 방식 중 하나를 사용할 수 있습니다.

```text
Native Messaging
WebSocket
Local REST API
```

초기 구현에서는 구조 단순성을 고려하여 Local REST API 또는 WebSocket 방식을 우선 검토합니다.

---

## 5. 문서 처리

### PyMuPDF

PDF 문서에서 텍스트를 추출할 때 사용합니다.

활용:

```text
PDF 본문 추출
페이지 단위 처리
검색용 텍스트 생성
```

### python-docx

Microsoft Word의 DOCX 문서에서 텍스트를 추출할 때 사용합니다.

---

## 6. SQLite

작업 로그 및 메타데이터 저장에 사용합니다.

저장 예:

```text
프로그램
창 제목
URL
파일 경로
열람 시간
활성 시간
세션 정보
```

선정 이유:

- 별도 데이터베이스 서버가 필요하지 않음
- 로컬 데스크톱 프로그램에 적합함
- SQL 기반 조건 검색 가능
- Python 기본 생태계와 연동이 쉬움

---

## 7. 벡터 데이터베이스

### 1순위 후보: ChromaDB

초기 개발에서는 ChromaDB 사용을 우선 고려합니다.

장점:

- Python 연동이 간단함
- 로컬 저장 가능
- 메타데이터 연동이 쉬움
- RAG 프로토타이핑에 적합함

### 대안: FAISS

벡터 검색 성능과 단순성이 중요할 경우 FAISS를 사용할 수 있습니다.

---

## 8. 임베딩

텍스트를 의미 검색 가능한 벡터로 변환합니다.

### 로컬 임베딩

후보:

```text
Sentence Transformers
```

장점:

- 외부 전송 없이 처리 가능
- 개인정보 보호에 유리함

### API 기반 임베딩

후보:

```text
OpenAI Embedding API
```

장점:

- 구현이 간단함
- 높은 품질의 임베딩 사용 가능

초기 설계에서는 개인정보 보호를 위해 로컬 임베딩 사용을 우선 고려합니다.

---

## 9. RAG 프레임워크

후보:

```text
LangChain
LlamaIndex
```

프레임워크 자체가 프로젝트의 핵심은 아니며 다음 기능을 단순화하기 위한 도구로 사용합니다.

- 검색기 구성
- 프롬프트 구성
- LLM 연결
- 검색 결과 전달
- 응답 구조화

---

## 10. FastAPI

브라우저 확장 프로그램과 데스크톱 UI, Python 백엔드 간 통신을 위한 로컬 API 서버로 사용할 수 있습니다.

예시 API:

```text
POST /context/browser
POST /context/clipboard
GET  /search
GET  /timeline
POST /settings/privacy
```

---

## 11. PySide6

Windows 데스크톱 사용자 인터페이스 구현에 사용합니다.

주요 화면:

- 검색창
- 검색 결과
- 출처 상세정보
- 작업 타임라인
- 기록 상태
- 개인정보 설정

Python 백엔드와 동일 언어로 개발할 수 있다는 점이 장점입니다.
