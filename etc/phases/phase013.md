# Phase 13 - 근거 기반 RAG

## 목표
검색된 실제 작업 기록만을 근거로 사용자 질문에 답변하고, 사용자가 근거 출처를 확인할 수 있도록 한다.

## Client
- [ ] 생성 답변 표시
- [ ] 답변 근거 목록
- [ ] 근거별 URL / 파일 경로
- [ ] 근거별 열람 시각
- [ ] 근거 상세보기
- [ ] 근거 부족 상태 표시

## Backend
- [ ] 상위 검색 근거 선택
- [ ] 중복 근거 제거
- [ ] 답변용 근거 구성
- [ ] 검색 근거 기반 응답 생성
- [ ] 근거 밖 출처 생성 방지
- [ ] 근거 부족 기준 적용
- [ ] 외부 전달 전 민감정보 재검사

## Shared
- [ ] RAG 요청 구조
- [ ] 답변 구조
- [ ] 근거 출처 구조

## Tests
- [ ] 단일 출처 질문
- [ ] 여러 출처 질문
- [ ] 비슷한 문서 구분
- [ ] 근거가 없는 질문
- [ ] 존재하지 않는 URL 생성 여부
- [ ] 차단/민감 데이터 포함 여부

## 완료 조건
- [ ] 검색된 기록을 기반으로 답변할 수 있다.
- [ ] 답변의 실제 출처를 함께 표시한다.
- [ ] 충분한 근거가 없으면 임의 답변을 생성하지 않는다.
