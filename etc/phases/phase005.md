# Phase 5 - 기본 개인정보 보호

## 목표
민감한 작업 정보가 저장되기 전에 차단할 수 있는 기본 보호 계층을 만든다.

## Client
- [ ] 기록 일시정지 / 재개
- [ ] 차단 프로그램 목록 입력
- [ ] 현재 기록 가능 여부 표시

## Backend
- [ ] 전체 기록 일시정지
- [ ] 프로그램 차단 검사
- [ ] 민감 문자열 패턴 검사
- [ ] 저장 전 개인정보 보호 검사
- [ ] 차단 사유 구분

## Shared
- [ ] 개인정보 설정 구조
- [ ] 기록 상태 구조

## Tests
- [ ] 기록 일시정지 중 저장되지 않음
- [ ] 차단 프로그램 활성 시 저장되지 않음
- [ ] 민감 문자열 차단
- [ ] 기록 재개 후 정상 저장
- [ ] 기존 기록에는 영향 없음

## 완료 조건
- [ ] 사용자가 전체 기록을 즉시 중지할 수 있다.
- [ ] 지정 프로그램의 기록이 저장되지 않는다.
- [ ] 기본 민감 문자열이 저장되지 않는다.
