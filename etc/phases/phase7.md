# Phase 7 - 브라우저 기본 연동

## 목표
Chrome/Edge의 현재 탭 제목과 URL을 Windows 작업 기록에 연결한다.

## Browser
- [ ] 확장 프로그램 기본 실행
- [ ] 현재 활성 탭 감지
- [ ] 탭 제목 수집
- [ ] URL 수집
- [ ] 탭 변경 이벤트 감지
- [ ] Backend로 정보 전달

## Backend
- [ ] 브라우저 정보 수신
- [ ] Windows 활성 브라우저 작업과 연결
- [ ] URL 변경 처리
- [ ] 브라우저 작업 기록 갱신
- [ ] URL 차단 검사

## Client
- [ ] 최근 작업 기록에 URL 표시
- [ ] 차단 URL 설정 입력

## Tests
- [ ] Chrome 탭 전환
- [ ] Edge 탭 전환
- [ ] 동일 탭 URL 변경
- [ ] 새 탭 / 빈 탭
- [ ] 차단 URL
- [ ] Browser와 Windows 기록 연결

## 완료 조건
- [ ] Chrome/Edge의 페이지 제목과 URL을 기록할 수 있다.
- [ ] 브라우저 탭 변경이 작업 기록에 반영된다.
- [ ] 차단 URL은 저장되지 않는다.
