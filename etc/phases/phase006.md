# Phase 6 - 클립보드 수집

## 목표
사용자가 복사한 텍스트를 현재 작업 맥락과 연결하여 저장한다.

## Client
- [ ] 클립보드 기록 사용 여부 설정
- [ ] 최근 작업 상세에서 관련 복사 텍스트 확인

## Backend
- [ ] 텍스트 클립보드 변화 감지
- [ ] 동일 내용 반복 복사 방지
- [ ] 복사 시각 기록
- [ ] 현재 활성 작업과 연결
- [ ] 개인정보 필터 적용
- [ ] 과도한 길이 제한

## Tests
- [ ] 일반 텍스트 복사
- [ ] 동일 텍스트 반복 복사
- [ ] 프로그램 전환 직후 복사
- [ ] 민감 문자열 복사
- [ ] 기록 일시정지 중 복사

## 완료 조건
- [ ] 복사 텍스트가 현재 작업과 연결된다.
- [ ] 민감 텍스트는 저장되지 않는다.
- [ ] 중복 복사로 기록이 불필요하게 증가하지 않는다.
