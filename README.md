# ContextTrace

> Windows 작업 로그 기반 개인 지식 출처 역추적 RAG 시스템

ContextTrace는 Windows 환경에서 사용자의 작업 맥락을 자동으로 수집하고,
로컬 지식 저장소에 축적한 뒤 자연어 질의를 통해 과거에 열람한 정보의
출처와 작업 맥락을 다시 찾을 수 있도록 지원하는 개인용 리서치 어시스턴트입니다.
