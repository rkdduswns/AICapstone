# Phase 14 - 작업 세션·타임라인·최종 안정화

## 목표
개별 기능을 하나의 사용자 흐름으로 완성하고, 시간적으로 연결된 작업을 세션과 타임라인으로 확인할 수 있도록 한다.

## Backend
- [ ] 시간 간격 기반 작업 세션 구성
- [ ] 세션 시작 / 종료 계산
- [ ] 세션과 작업 기록 연결
- [ ] 세션 관련 자료 조회
- [ ] 선택 기록 삭제
- [ ] 전체 기록 삭제
- [ ] 장시간 수집 안정성 확인
- [ ] 종료/재시작 데이터 일관성 확인
- [ ] 검색 응답 시간 점검

## Client
- [ ] 작업 타임라인
- [ ] 작업 세션 상세보기
- [ ] 개인정보 설정 화면 정리
- [ ] 기록 삭제 기능
- [ ] 검색 → 답변 → 출처 이동 흐름 정리
- [ ] 오류 / 빈 결과 상태 정리

## Integration
- [ ] 웹 열람 → 기록 → 의미 검색 → URL 확인
- [ ] PDF 열람 → 내용 검색 → 파일 경로 확인
- [ ] 기록 → 검색 → RAG → 근거 확인
- [ ] 차단 앱 → 저장되지 않음
- [ ] 차단 URL → 저장되지 않음
- [ ] 일시정지 → 재개
- [ ] 재시작 후 기존 기록 검색
- [ ] 장시간 실행

## 2인 작업 예시
**개발자 A:** Timeline/Session UI, 개인정보 설정, UX 정리  
**개발자 B:** Session 구성, 데이터 관리, 성능/안정성  
**공동:** 전체 E2E, 버그 수정, 최종 시연

## 완료 조건
- [ ] 웹과 로컬 문서의 전체 출처 역추적 흐름이 동작한다.
- [ ] 관련 작업을 세션과 타임라인으로 확인할 수 있다.
- [ ] 개인정보 보호 규칙이 전체 파이프라인에 적용된다.
- [ ] 프로그램 재시작 후에도 기존 기록을 검색할 수 있다.
- [ ] 대표 시연 시나리오를 반복해도 안정적으로 동작한다.
