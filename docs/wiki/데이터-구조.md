# 데이터 구조

ContextTrace에서는 **작업 메타데이터**, **문서 조각**, **작업 세션**을 분리하여 관리합니다.

---

## 1. 작업 기록

사용자가 특정 프로그램이나 문서를 실제로 열람한 기록입니다.

### 주요 필드

| 필드 | 설명 |
|---|---|
| `id` | 작업 기록 식별자 |
| `application` | 프로그램명 |
| `process` | 프로세스명 |
| `window_title` | 창 제목 |
| `url` | 웹페이지 URL |
| `file_path` | 로컬 파일 경로 |
| `opened_at` | 활성화 시작 시각 |
| `last_active_at` | 마지막 활성 시각 |
| `active_duration` | 총 활성 시간 |
| `foreground_count` | 다시 활성화된 횟수 |
| `clipboard_text` | 관련 복사 텍스트 |
| `session_id` | 작업 세션 식별자 |

---

## SQLite 예시

```sql
CREATE TABLE context_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    application TEXT,
    process TEXT,
    window_title TEXT,
    url TEXT,
    file_path TEXT,
    opened_at DATETIME,
    last_active_at DATETIME,
    active_duration INTEGER DEFAULT 0,
    foreground_count INTEGER DEFAULT 1,
    clipboard_text TEXT,
    session_id INTEGER
);
```

---

## 2. 문서 조각

긴 문서는 검색 정확도를 높이기 위해 작은 단위로 분할합니다.

### 주요 필드

| 필드 | 설명 |
|---|---|
| `id` | 문서 조각 식별자 |
| `context_id` | 원본 작업 기록 ID |
| `chunk_index` | 문서 내 순서 |
| `text` | 실제 텍스트 |
| `embedding_id` | 벡터 DB 식별자 |

예:

```text
원본 PDF
    ↓
문서 조각 1
문서 조각 2
문서 조각 3
문서 조각 4
```

각 문서 조각은 원본 작업 기록과 연결되어 있기 때문에 검색 결과에서 다시 파일명, URL, 열람 시간을 추적할 수 있습니다.

---

## 3. 벡터 메타데이터

벡터 데이터베이스에는 임베딩뿐 아니라 원본 출처와 연결할 수 있는 메타데이터를 함께 저장합니다.

예:

```json
{
  "context_id": 1827,
  "source_type": "web",
  "application": "Google Chrome",
  "title": "SaaS Metrics Report",
  "url": "https://example.com/saas-report",
  "timestamp": "2026-09-10T14:22:13"
}
```

---

## 4. 작업 세션

시간적으로 가까운 작업 기록들을 하나의 작업 단위로 그룹화합니다.

### 주요 필드

| 필드 | 설명 |
|---|---|
| `id` | 세션 ID |
| `started_at` | 시작 시각 |
| `ended_at` | 종료 시각 |
| `title` | 세션 제목 |
| `summary` | 세션 요약 |

예시:

```text
세션: AI Agent 구현 조사

13:10
Chrome - OpenAI Agents

13:20
Acrobat Reader - Agent Survey.pdf

13:35
VS Code - rag.py

13:48
Chrome - LangGraph Documentation
```

---

## 5. 출처 연결 구조

ContextTrace에서는 모든 검색 결과가 다시 원본 기록으로 연결될 수 있어야 합니다.

```text
검색 결과 문서 조각
      ↓
context_id
      ↓
작업 기록
      ↓
URL / 파일 경로
      ↓
열람 시각
      ↓
작업 세션
```

이 연결 관계가 출처 역추적 기능의 핵심입니다.
