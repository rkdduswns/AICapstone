# Client 관리·기록·문서·실행 편의 개선

작업일: 2026-11-14 (KST). 기준: `client_dev 6a2cc89`, 확인한 `main 7e0991e`.
작업 브랜치: `feat/client-management-usability`. 현재 서버 요청 형식과 PR #22의 출처 호환 검증을 보존한다.

## 목적·범위·선행조건

작은 검색창에서 관리 화면으로 오가며 실제 기록과 문서를 읽는 공간을 확보하고, 전송 상태와 저장 결과를 구분한다.
선행조건은 기존 Client·HTTP·최근 기록·문서 가져오기 연결이다. 실행 코드 변경은 Client에 한정한다.
Backend·DB·Shared·브라우저 확장·의존성·검색/LLM API 계약은 변경하지 않는다.

## 구현

1. **관리 공간:** 연결 상태·확인 동작을 한 줄에 배치하고 버전·주소·확인 시각은 연결 정보에서 펼친다.
   기록 상태와 일시정지는 계속 표시한다. 일반 실행의 미지원 조건 검색 탭은 숨기고, 기존 가상 검색 미리보기는 유지한다.
2. **최근 기록:** 목록/상세 높이를 끌어서 조절한다. 좁은 화면의 긴 경로 열은 접되 원문 경로는 선택 상세에 유지한다.
   제목·프로그램·프로세스·웹/파일 출처의 빠른 필터는 **현재 받은 최근 20건 안에서만** 적용하며 검색·목록 조회 요청을 추가하거나 원래 정렬을 바꾸지 않는다. 선택한 기록의 기존 본문 조회는 유지한다.
   숨겨진 행은 연결 동작 대상으로 사용할 수 없고 갱신 시 보이는 같은 작업 ID를 다시 선택한다.
3. **문서 가져오기:** 파일명·바이트 수·선택 연결 대상을 전송 중에도 표시한다. 실제 전송량과 서버 응답 대기를 나눈다.
   서버 추출 진행률은 만들지 않으며 성공 응답 검증 이후에만 완료·연결 결과를 표시한다.
   완료한 문서와 수동 새로고침의 선택을 ID로 복원하고 목록/본문 크기도 조절한다. 403·출처 대조·자동 재전송 금지는 유지한다.
4. **실행·조작:** 일반 시작과 진단 모두 기존 서버에 연결 확인을 한 번 예약한다. 서버를 새로 실행하거나 보호 설정을 바꾸지 않는다.
   앱 안에서 `Ctrl+L`은 검색 복귀, `F5`는 현재 화면 조회다. 업로드·보호 설정 쓰기 중에는 F5·메뉴의 연결 재확인이 쓰기 요청을 취소하지 않는다.
5. **표시 설정:** 정상 실행에서 창 위치·관리 크기·최근 기록/문서/답변의 펼친 영역 비율만 기억한다.
   검색어·필터·본문·URL·파일 경로·작업 ID·응답은 저장하지 않는다. 진단 실행과 테스트는 사용자 표시 설정을 읽거나 덮어쓰지 않는다.
   손상 값은 기본값으로 처리하며 모니터가 사라지거나 더 작아지면 창 크기와 위치를 사용 가능한 화면에 맞춘다.
6. **읽기 디자인:** 주동작·보조동작 강조를 구분하고 읽기 영역의 반복 테두리를 줄였다.
   원문과 인용 문자 위치를 유지한 채 여백·행간·문단 간격을 보완한다. HTML/Markdown·외부 자원 로딩을 새로 추가하지 않는다.

## 검증·완료조건

완료조건은 위 화면 동작과 기존 요청·출처·개인정보 경계의 회귀 검증 통과이며, 실제 검색/RAG 완료와 구분한다.

- 로컬 Windows Python 3.14.7·Qt 오프스크린·맑은 고딕 10pt에서 통합 중 전체 **767 통과·1 건너뜀**을 확인했다.
- 이후 검토에서 보완한 작은 모니터 복원·쓰기 중 재확인을 포함한 실행 편의 **7개**도 통과했다.
- 관리·최근 기록, 문서 가져오기/기존 서버, 표시 설정과 기존 답변/근거 회귀를 확인했다. Qt 150% 배율의 작은 화면·필터·영역 조절·작은 모니터 복원 관련 **12개**도 통과했다.
- 관리 기록·문서 완료·답변/근거의 가상 자료 PNG를 확인했다. 새 요청 필드·서버 구현을 가상으로 완료 처리하지 않았다.
- `41210fe` Windows x64 EXE를 실제 실행해 소스 import 차단·한글/공백 경로·버전 메타데이터·HTTP/SQLite·PDF/DOCX·403·설정 재시작 복원·native Qt Client 연결 **8항목 모두 통과**했다. `BUILD.json`은 해당 빌드 커밋을 기록한다.
- 최종 Windows Python 3.11·3.12 전체 검사와 실제 client_dev 반영 SHA는 [PR #23](https://github.com/rkdduswns/AICapstone/pull/23)의 GitHub 검사·병합 기록을 따른다.

Windows 실제 한글 입력기·운영체제 배율·물리 다중 모니터 조작은 별도 수동 검증으로 남는다.
검색·LLM API, 자동 수집/URL 차단, 메모·중요도·민감 본문 동의와 트레이/전역 단축키는 이번 단계에 추가하지 않는다.
