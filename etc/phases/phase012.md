# Phase 12 - 의미 검색 및 혼합 검색

## 목표
사용자가 정확한 제목을 기억하지 못해도 내용의 의미로 자료를 찾고, 조건 검색과 의미 검색을 함께 사용할 수 있도록 한다.

## Client
- [ ] 자연어 검색 입력
- [ ] 관련 내용 미리보기
- [ ] 검색 결과 관련도 표시 방식 정리

## Backend
- [ ] 질의 의미 검색
- [ ] 의미 유사도 기반 후보 추출
- [ ] 시간 조건 + 의미 검색
- [ ] 프로그램 조건 + 의미 검색
- [ ] 출처 유형 + 의미 검색
- [ ] 결과 재정렬
- [ ] 활성 시간 / 재방문 신호 반영 가능 구조

## Tests
- [ ] 내용만 기억하는 질의
- [ ] 다른 표현의 의미 검색
- [ ] 시간 + 의미 질의
- [ ] 프로그램 + 의미 질의
- [ ] 웹과 PDF 혼합 결과
- [ ] 관련 없는 질의
- [ ] 실제 출처 연결 검증

## 완료 조건
- [ ] 내용의 의미만으로 과거 자료를 찾을 수 있다.
- [ ] 시간·프로그램 조건과 의미 검색을 함께 사용할 수 있다.
- [ ] 검색 결과에서 실제 URL/파일 경로를 확인할 수 있다.
