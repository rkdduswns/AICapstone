# Client 개인정보 설정 확인·초안 화면 정리

작업일: 2026-11-14 (KST). 기준: `client_dev f4531de`, 확인한 `main 7e0991e`.
작업 브랜치: `feat/client-privacy-status`.

## 목적·선행조건·범위

Phase 14의 Client `개인정보 설정 화면 정리`를 진행한다. 기존 설정 API와 검증된 서버 응답을 사용해
확인된 적용값·미적용 입력·적용 중·확인 실패·미지원 기능을 구분한다.
선행조건은 현재 개인정보 설정·독립 PUT·응답 값 확인·조회 복구·초안 보존 구현이다.
기존 동작을 재구현하지 않고 Client 표시와 편집 영역을 정리한다.

Backend·DB·Shared·브라우저 확장·의존성·API 경로/필드·보호 판정·저장 정책을 변경하지 않는다.
메모·중요도·민감 본문 저장 동의·URL 차단 서버 구현은 추가하지 않는다.

## 구현 경계

- 서버가 확인한 일시정지·클립보드 옵션·차단 목록을 편집 초안과 구분한다.
  일시정지 꺼짐만으로 기록 허용을 추정하지 않고 기존 서버의 실제 기록 사유를 별도로 유지한다.
- 적용된 프로그램 목록은 읽기 전용으로 필요할 때 확인한다. 입력과 서버 확인 목록의 차이를 안내한다.
  되돌리기는 현재 확인된 값으로 로컬 초안을 복원하며 서버에 쓰지 않는다.
- 적용 중·오류·재연결에서는 예전 확인값을 현재 설정처럼 표시하지 않는다.
  미적용 프로그램·URL 초안과 입력은 기존 규칙대로 메모리에서 보존한다.
- URL 차단의 지원 여부는 정상 응답으로 확인한 선택 필드에서만 판단한다.
  `blocked_urls=[]`는 지원하는 빈 목록, `None`/생략은 확인된 응답에서의 미지원이다.
  연결 대기·적용 중·실패는 지원 미확인으로 구분한다. 미지원 폼은 안내로 대체하고 지원 확인 시 기존 편집 흐름을 사용한다.
  전체 규칙을 제거한 빈 초안도 미지원 응답 때문에 삭제 의도가 사라지지 않도록 마지막 비교 기준과 함께 보존한다.
- 기존 쓰기 잠금·명시적 적용·서버 응답 값 대조·403 실패·자동 재전송 금지를 유지한다.
  UI 보기·목록 확인·되돌리기에서 PUT을 보내거나 입력 초안을 새로 저장하지 않는다.

## 검증·완료조건

1. 확인된 요약과 적용 목록, 미적용 초안의 구분 및 읽기 전용 여부.
2. 일시정지 꺼짐과 실제 기록 차단 상태의 구분.
3. 미지원·미확인·지원하는 빈 URL 목록의 구분과 지원 복구.
4. 폴링·다른 설정 적용·실패·재연결에서 초안 보존, 상태 확인 불가 시 옛 적용값 제거.
5. 보기·되돌리기·재확인의 쓰기 없음, 기존 독립 PUT·실패·echo 불일치·복구 회귀.
6. 작은 화면·키보드·가상 자료 시각 확인과 기존 실제 서버 연결.

완료조건은 위 Client 표시·편집·회귀 검증 통과다.

- Windows Python 3.14.7·Qt 오프스크린·맑은 고딕 10pt에서 신규 상태 검증 16개와 기존 개인정보·실제 Backend HTTP·소형 창·관리 화면 검증을 포함한 관련 회귀 **94개 통과**를 확인했다.
- Qt 150% 배율에서 신규 상태 검증과 작은 관리/출처 화면 검증 **18개 통과**를 확인했다.
- 가상 서버 자료로 적용 목록·편집 초안·확인된 미지원·조회 실패 화면을 확인했다. 실제 사용자 자료나 사용자 설정 저장은 사용하지 않았다.
- Ruff·공백 검사와 문서 링크·14개 Phase 체크 개수의 일치를 확인한다. Phase 14는 이번 Client 설정 화면 정리만 완료하여 **1/28**로 관리한다.
- 최종 Windows Python 3.11·3.12 전체 검사, 새 EXE 실행 결과 및 실제 `client_dev` 반영 SHA는 이 작업 PR의 GitHub 검사·병합 기록을 따른다.

실제 운영체제 한글 입력기·물리 다중 모니터 수동 검증은 남아 있다.
Client 화면 정리 완료를 URL 차단 서버 구현이나 Phase 14 전체 완료로 해석하지 않는다.
