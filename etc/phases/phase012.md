# Phase 12 - 의미 검색 및 혼합 검색

## 목표
사용자가 정확한 제목을 기억하지 못해도 내용의 의미로 자료를 찾고, 조건 검색과 의미 검색을 함께 사용할 수 있도록 한다.

## 진행 상태와 범위

- 2026-11-06 (KST) `main`의 `7c30798`에서 분기한 `feat/phase12-client`에서 Client 미리보기를 추가했다.
- **Client 미리보기 완료 / 전체 IN_PROGRESS**. 자연어 문장과 선택 조건을 제출하면 메모리의 가상 웹·PDF 결과를 표시한다. 프로그램·출처 유형·마지막 활성 날짜 범위를 선택할 수 있다.
- 순위는 결과 공급자가 전달한 순서를 1부터 표시한다. 목록에는 관련 본문의 일부를, 선택 상세에는 전체 조각과 확보 당시 URL 또는 파일 경로를 일반 텍스트로 표시한다. 열람 시작·마지막 활성·본문 확보 시각을 각각 구분한다.
- 실제 검색 API 연결, 임베딩·유사도 계산, Chrome 수집과 SQL 저장은 별도 범위다. 이 미리보기의 입력과 응답 구조는 화면 검증용이다.
- Windows Python 3.14.7의 Qt 오프스크린에서 신규 화면 테스트 6개를 포함해 Client 테스트 451개가 통과했고 POSIX 전용 1개를 건너뛰었다. 입력·조건 전달, 순위·출처 표시, 결과 초기화, 잘못된 기간, 빈 결과와 오류를 확인했다.
- 가상 결과·빈 결과·오류의 PNG 저장과 Ruff·의존성 검사를 확인했다.

## Client 미리보기 실행

```powershell
python tools/preview_phase12_client.py
python tools/preview_phase12_client.py --state empty --snapshot phase12-empty.png
```

기본 상태 `ready`는 질의 문장과 무관한 고정 웹·PDF 결과에 선택 조건을 적용한다. `--state empty`와 `--state error`로 빈 결과와 오류 안내를 확인할 수 있다. `--snapshot PATH`를 지정하면 미리보기 화면을 PNG로 저장하고 종료한다.
