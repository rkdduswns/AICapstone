# Phase 10 - 검색 데이터 구축

## 목표
웹과 로컬 문서 내용을 검색 가능한 작은 단위로 가공하고 의미 검색용 데이터를 만든다.

## Backend
- [ ] 텍스트 정규화
- [ ] 긴 문서 분할
- [ ] 짧은/불필요한 조각 제거
- [ ] 각 조각에 원본 작업 ID 연결
- [ ] 의미 검색용 데이터 생성
- [ ] 검색용 데이터 저장
- [ ] 원본 삭제 시 검색 데이터 처리

## Shared
- [ ] 검색 문서 조각 구조 정의
- [ ] 출처 메타데이터 구조 정의

## Tests
- [ ] 긴 웹페이지 분할
- [ ] 긴 PDF 분할
- [ ] 아주 짧은 텍스트
- [ ] 중복 조각
- [ ] 검색 조각 → 원본 URL 복원
- [ ] 검색 조각 → 원본 파일 경로 복원

## 완료 조건
- [ ] 웹/문서 내용을 동일한 검색 단위로 다룰 수 있다.
- [ ] 모든 검색 단위가 실제 원본 작업과 연결된다.
- [ ] 의미 검색에 사용할 데이터가 준비된다.
