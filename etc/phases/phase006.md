# Phase 6 - 클립보드 수집

## 목표
사용자가 복사한 텍스트를 현재 작업 맥락과 연결하여 저장한다.

상태: **Client DONE / 전체 IN_PROGRESS** (2026-10-08). 작업 브랜치: `feat/phase6-client`.
[클립보드 API 계약](../../docs/dev/clipboard-api.md), [Client 구현·검증 결과](../../docs/reports/phase6-client.md).

## 범위와 선행조건
- Phase 5 Client의 개인정보 설정과 Phase 4 최근 기록을 확장한다. 아직 미병합인 `feat/phase5-client`를 기반으로 한다.
- Client는 기록 사용 설정과 저장 결과 조회만 구현한다. 실제 OS 클립보드를 읽거나 저장하지 않는다.
- 실제 수집은 Backend Phase 2–5 감지·작업 연결·저장 전 개인정보 검사가 선행되어야 한다.
- 실제 클립보드/저장소 검증은 Backend 연결 후 수행한다.
