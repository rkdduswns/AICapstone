# Phase 5 - 기본 개인정보 보호

## 2026-10-21 통합 상태

실제 설정 API와 수집기가 같은 정책을 공유한다. 일시정지·재개·차단 및 민감 패턴 검사를 자동 검증했다. 설정 영속화와 Windows 수동 검증은 남아 있다.
브랜치: `feat/client-backend-integration`. [통합 검증](../../docs/reports/client-backend-integration.md).
아래 기존 날짜의 범위 설명은 최초 Client 선행 개발 시점의 기록이다. 전체 Phase는 IN_PROGRESS다.

## 목표
민감한 작업 정보가 저장되기 전에 차단할 수 있는 기본 보호 계층을 만든다.

상태: **Client DONE / 전체 IN_PROGRESS** (2026-10-07). 작업 브랜치: `feat/phase5-client`.
[개인정보 API 계약](../../docs/dev/privacy-api.md), [Client 구현·검증 결과](../../docs/reports/phase5-client.md).

## 범위와 선행조건
- 최신 main의 Phase 2–4 Client를 기반으로 제어 화면과 Shared 계약을 구현한다.
- Client 검증은 가상 HTTP 응답으로 진행한다. 실제 수집/저장 차단 및 재개 테스트는 Backend 연결 후 수행한다.
- 실제 보호 계층은 Backend 감지·시간 추적·저장 흐름과 연동하며 실제 사용자 기록 저장 전에 적용한다.
