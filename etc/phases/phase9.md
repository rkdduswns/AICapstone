# Phase 9 - 로컬 문서 내용 수집

## 목표
PDF와 DOCX 등 로컬 문서의 내용을 추출하고 실제 파일 경로와 작업 기록에 연결한다.

## Backend
- [ ] 열려 있는 파일 경로 식별
- [ ] 지원 파일 유형 판별
- [ ] PDF 텍스트 추출
- [ ] DOCX 텍스트 추출
- [ ] 문서 내용과 파일 경로 연결
- [ ] 열람 시각과 작업 기록 연결
- [ ] 동일 파일 재처리 최소화

## Client
- [ ] 최근 기록에서 파일 경로 표시
- [ ] 파일 출처 상세보기

## Tests
- [ ] 일반 PDF
- [ ] 여러 페이지 PDF
- [ ] 일반 DOCX
- [ ] 내용 없는 문서
- [ ] 이동/삭제된 파일
- [ ] 동일 파일 재열람

## 완료 조건
- [ ] PDF 내용을 추출할 수 있다.
- [ ] DOCX 내용을 추출할 수 있다.
- [ ] 추출된 내용에서 실제 파일 경로로 역추적할 수 있다.
