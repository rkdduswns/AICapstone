# Phase 4 - 작업 기록 저장 및 조회

## 목표
메모리에만 존재하던 작업 정보를 로컬에 저장하고 프로그램 재시작 후에도 조회할 수 있도록 한다.

## Client
- [ ] 최근 작업 기록 간단 조회 화면
- [ ] 최근 기록 새로고침

## Backend
- [ ] 작업 기록 생성
- [ ] 작업 기록 갱신
- [ ] 활성 시간 저장
- [ ] 재방문 횟수 저장
- [ ] 최근 기록 조회
- [ ] 프로그램 재시작 후 기존 기록 유지

## Shared
- [ ] 작업 기록 구조 확정
- [ ] 최근 기록 응답 구조 정의

## Tests
- [ ] 새 기록 생성
- [ ] 기존 기록 갱신
- [ ] 재시작 후 기록 조회
- [ ] 시간 순 정렬
- [ ] 잘못된/누락된 값 처리

## 완료 조건
- [ ] 실제 작업 기록이 로컬에 저장된다.
- [ ] 프로그램을 재실행해도 기존 기록이 유지된다.
- [ ] Client에서 최근 작업 기록을 확인할 수 있다.
