# 코드 학습 공간

복잡한 코드를 원본과 분리해 복사하고, 단계별 상세 설명을 요청하는 공간입니다.
이 폴더의 코드는 학습 당시의 사본이며 실제 프로젝트 구현 기준이 아닙니다.

## 주제별 구성

설명이 필요할 때에만 아래 형태로 주제 폴더를 추가합니다.

```text
etc/study/
  README.md
  TEMPLATE.md
  001-backend-health/       # 예시: 요청 시 생성
    source.py              # 선택한 원본의 학습용 사본
    explanation.md         # TEMPLATE.md를 복사해 작성
```

1. 최신 `src/` 또는 `tests/` 원본을 먼저 확인합니다.
2. 요청한 코드만 주제 폴더에 복사합니다. 외부 비밀값·실제 사용자 데이터는 복사하지 않습니다.
3. 사본 첫 주석과 설명 문서에 원본 경로, 원본 commit SHA, 복사 날짜를 남깁니다.
4. 원본 내용을 설명하고 싶은 경우 사본은 그대로 두고 설명 문서에 주석을 풉니다.
   사본에 주석을 추가하거나 코드를 단순화하면 원본과 달라진 부분을 명시합니다.
5. 여러 파일을 복사하면 기존 상대 경로를 주제 폴더 안에서 유지하고 파일별 출처를 기록합니다.

## 설명 요청 예시

> src/client/backend_client.py를 etc/study/001-backend-connection에 복사하고,
> 각 함수의 역할, 호출 순서, Qt 이벤트 루프, timeout과 예외 처리를 단계별로 설명해줘.
> 학습용 사본에 상세한 한국어 주석을 달고 원본은 수정하지 마.

## 프로젝트와의 분리

- Git 추적 대상입니다. `.gitignore`로 숨기지 않습니다.
- `src/`, `tests/`에서 참조·import·실행·데이터 로드를 금지합니다.
- 학습용 코드의 수정은 원본에 자동 반영하지 않으며, 원본 변경도 사본에 자동 반영하지 않습니다.
- 학습 파일 이름이 `test_*.py`여도 저장소 루트의 pytest 수집 대상에서 제외합니다.
- Ruff 검사에서 제외하며, 명시적으로 해당 파일을 전달해도 `force-exclude`가 적용됩니다.
- 패키지는 `src/`에서만 탐색하며, 소스 배포에서도 `MANIFEST.in`으로 이 폴더를 제외합니다.
- 이 설정은 도구의 검색·검사·패키징 범위와 개발 규칙입니다.
  Python 자체의 강제 실행이나 임의 파일 접근을 차단하는 보안 격리는 아닙니다.
