# Phase 6 Client 구현 및 검증

작업 확인일: 2026-10-08. 브랜치: `feat/phase6-client`.
상태: **Client DONE / 전체 IN_PROGRESS**. 실제 수집·필터·저장 검증은 Backend 연결 후 수행한다.

## 기준과 범위

최신 main `d9c47d1be5469085728e18dc9d53e2de0625459b`와 PR #8의 미병합 상태를 확인했다.
Phase 6 설정이 Phase 5 개인정보 제어에 의존하므로
`feat/phase5-client`의 `90cc3c720fedb501af4e133bf03ea4246e3e3698`에서 분기했다.
PR 기준도 `feat/phase5-client`로 하여 Phase 6만 비교한다. 선행 PR 병합 후 main 기준으로 갱신한다.

기획의 작업-클립보드 관계, `phase006.md`, 최신 Shared/API와 실제 화면을 대조했다.
추상 모델의 단일 `clipboard_text` 관계를 작업 하나에 연결된 여러 복사 이벤트와 별도 상세 조회로 구체화했다.
기획 원문은 수정하지 않았고 Backend 저장 형식을 강제하지 않는다.

## 구현

- 개인정보 보호 탭의 클립보드 기록 켜기/끄기. 확인된 목표값만 적용 표시.
- 선택 `clipboard_enabled` 필드로 구형 Phase 5 응답의 누락/null을 기능 미지원으로 구분.
- 전체 일시정지·차단 목록과 독립적인 설정 요청. 입력 초안 및 기존 보호 상태 의미 유지.
- 최근 작업 상세를 작업 정보/복사 텍스트 탭으로 나누고 본문은 상세 진입 시 조회.
- 복사 시각별 최근 최대 20개 항목, 읽기 전용 원문, 이전 항목 존재 표시, 수동 새로고침.
- 작업 선택/목록 새로고침/재연결/종료 시 이전 요청과 본문 제거.
- 작업 ID 인코딩과 응답 ID 일치 검사, 시각·개수·원문 길이·중복 ID 검증, 최신순 정렬.
- 가상 설정 및 복사 항목 미리보기. Phase 5 미리보기 서버/화면 흐름 재사용.

OS 클립보드를 읽거나 쓰지 않고 감지/필터/저장 로직을 추가하지 않았다.
Backend 실행 코드와 의존성은 변경하지 않았다. 설정과 본문을 Client 파일/로그에 저장하지 않는다.

## 검증

Windows 10 / Python 3.14.7 / Qt 6.11.2의 기존 환경을 사용했다.

| 범위 | 결과 |
|---|---|
| 신규 가상 HTTP/계약 검증 | 36개 추가 (설정 7, 복사 상세 29) |
| 기존 회귀 포함 전체 `pytest -q` | **222 passed**, 51.85초 |
| `ruff check src tests tools` | 통과 |
| `pip check` | 의존성 문제 없음 |
| Phase 6 상세/설정 미리보기 PNG | 한글, 줄바꿈, HTML 형태 원문, 시각별 선택, 켜기/끄기 배치 확인 |

Qt 이벤트 루프와 가상 HTTP 서버로 설정 미지원/타입 오류/켜기·끄기/적용 응답 불일치,
일시정지 및 목록 초안 보존, 상세 지연 조회, 항목 선택/새로고침/빈 목록,
다른 시간대 정렬, 최대 10,000자, 잘못된 필드/누락/중복/개수 초과,
HTTP 404/500/JSON 오류/다른 작업 응답/timeout/수동 복구를 확인했다.
특수문자 작업 ID 전송과 지연된 A 응답이 B 선택을 덮지 않는 동작,
기록 목록 새로고침과 창 종료 시 본문·요청 정리도 검증했다.

기존 Starlette/httpx deprecation warning 1건은 유지된다.
제한 환경의 단독 검사에서 발생한 pytest 캐시 경고는 전체 실행에서는 발생하지 않았다.
GitHub Windows Python 3.11/3.12 결과는 PR의 Actions 링크로 기록한다.

## 실제 통합에서 남은 항목

일반/반복 복사 감지, 복사 순간의 작업 연결, 민감 문자열·차단 프로그램·일시정지 중 저장 방지,
과도한 원문 저장 제한, 영속 저장과 재조회는 Backend 연결 후 검증한다.
Client의 텍스트 표시/길이 검사는 Backend의 수집 제한·중복 방지·저장 전 보호 구현을 대신하지 않는다.
개별 Phase와 통합 현황은 Client/Shared/가상 검증 6개만 완료로 표시하고 실제 완료 조건은 미완료로 유지했다.

API 및 통합 조건: [클립보드 계약](../dev/clipboard-api.md).
미리보기: `python tools/preview_phase6_client.py`, 설정 화면: `--settings`.
