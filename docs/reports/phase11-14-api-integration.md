## 검증 근거

Linux Python 3.12.14, Qt offscreen에서 **전체 Python 846개 통과**(227.66초),
브라우저 Node 테스트 **11개 통과**. Ruff(`src tests tools`)·의존성 검사·diff 공백 검사 통과.
14개 Phase 원본 체크와 진행 표의 상태·개수 일치 및 갱신 문서 상대 링크를 검사했다.
FastAPI TestClient의 upstream httpx 사용 중단 예정 경고 1개가 있으며 테스트 실패는 없다.
Windows 최소 EXE 빌드와 소스 없이 패키지만 실행하는 검증이 통과했다.
첫 Windows 전체 검증에서 Phase 14 테스트 두 건이 `detector=None`으로 실제 runner 창을 수집해
가상 DB의 세션에 섞이는 문제가 발견됐다. 해당 테스트에 창 없음 감지기와 자동 폴링 해제를
명시했다. 실제 프로그램의 기본 감지는 유지한다. 최종 Windows 재검증 결과는 PR Actions를 따른다.

OS 창 감지와 임베딩/생성 추론 출력은 제어된 대역을 주입했다. 그 밖의 HTTP·DB·추출·청크·유사도·필터·
근거 선택·Ollama HTTP 전송·Qt 화면은 실제 구현을 실행했다. 자동 테스트용 자료는 가상 자료다.

## 남은 검증과 완료 기준

이 Linux 환경에는 sentence-transformers 가중치와 실행 중인 Ollama가 없어 **실제 E5 추론·실제 LLM
답변 품질은 미검증**이다. 모델 오류를 숨기지 않는 동작은 확인한다. 기본 의존성과 ML 의존성을 분리했다.
최소 EXE 빌드는 ML 런타임/가중치/Ollama를 포함하지 않는다.

Windows 10/11 실제 창/복사/확장, 화면 배율/다중 모니터, 자동 탭/파일 감지, URL 차단, 장시간 수집,
실제 모델 검색 품질·응답 시간·시연은 남아 있다. 시간 근접성만으로 세션 자료를 연결하지 않는다.
Phase 11–14 체크는 자동 검증한 항목만 갱신하며 전체 완료로 확대하지 않는다.
실제 모델 준비 후 [수동 검증 순서](../dev/phase11-14-api-integration.md#검증-순서)를 수행한다.
