# Phase 8 - 웹페이지 본문 수집

## 목표
URL과 제목뿐 아니라 사용자가 실제로 본 웹페이지의 검색 가능한 텍스트를 확보한다.

## 진행 상태와 범위

- 2026-10-10: **Client DONE / 전체 IN_PROGRESS**, `feat/phase8-client`.
- Client 선행 개발을 위해 저장 웹 본문 확인 화면과 조회 계약을 추가한다.
- 선행조건: Phase 4 최근 기록, Phase 7 브라우저 출처. 미병합 `feat/phase7-client`에서 분기했다.
- 이번 범위: 본문·출처·수집 시각 표시, 상태/오류 처리, Shared 계약 및 가상 HTTP 검증.
- Client 완료 근거: 전체 297개 테스트, 정적 검사·의존성 검사·가상 화면 확인.
- Browser/Backend 실제 본문 수집·정제·중복 제거·저장 및 차단 검증은 남아 있다.
- [API 계약](../../docs/dev/web-content-api.md), [검증 보고서](../../docs/reports/phase8-client.md).
