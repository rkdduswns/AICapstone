# Phase 4 - 작업 기록 저장 및 조회

## 목표
메모리에만 존재하던 작업 정보를 로컬에 저장하고 프로그램 재시작 후에도 조회할 수 있도록 한다.

상태: **Client DONE / 전체 IN_PROGRESS** (2026-10-02).
[최근 기록 계약](../../docs/dev/recent-records-api.md)과 [Client 구현·검증 결과](../../docs/reports/phase4-client.md)를 따른다.

## 범위와 선행조건
- 이번 Client 작업은 Phase 3 Client의 시간 표시와 기존 비동기 통신을 기반으로 한다.
- Client는 최근 기록 조회·표시·새로고침을 담당한다. 데이터 저장 및 재방문 계산은 Backend에서 구현한다.
- 실제 저장 기능은 Backend Phase 2 감지와 Phase 3 시간 추적을 선행 조건으로 한다.
