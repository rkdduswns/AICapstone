초기 버전에서는 시스템의 핵심 가치인 **Windows 작업 기록 자동 수집과 출처 역추적**을 우선 완성합니다.

## 5. 개발 완료 기준

MVP는 다음 시나리오가 동작하면 핵심 목표를 달성한 것으로 봅니다.

### 시나리오 1

사용자가 Chrome에서 특정 웹페이지를 확인합니다.

시스템은 다음을 자동 저장합니다.

```text
페이지 제목
URL
열람 시각
활성 시간
관련 텍스트
```

이후 사용자가 다음과 같이 질문합니다.

> 지난주 Chrome에서 읽었던 SaaS 수익 모델 자료 찾아줘.

시스템은 관련 페이지와 URL, 열람 시간을 반환합니다.

### 시나리오 2

사용자가 PDF 문서를 열어 읽습니다.

시스템은 파일명과 파일 경로, 열람 시각을 저장합니다.

이후 사용자가 내용 일부만 기억한 상태에서 자연어로 검색해 해당 PDF를 찾을 수 있습니다.

### 시나리오 3

차단 목록에 등록된 프로그램이나 URL에서는 작업 기록이 생성되지 않습니다.

---

## 6. MVP에서 제외하는 기능

개발 범위를 유지하기 위해 다음 기능은 초기 버전에서 구현 목표로 잡지 않습니다.

```text
화면 전체 캡처 및 OCR
추천 시스템
Knowledge Graph
복잡한 자동 요약
클라우드 동기화
모바일 지원
macOS / Linux 지원
```

핵심은 기능 수가 아니라 **작업 기록을 안정적으로 수집하고, 나중에 정확한 출처를 다시 찾을 수 있는가**입니다.
