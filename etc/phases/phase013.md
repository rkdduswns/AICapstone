# Phase 13 - 근거 기반 RAG

## 목표
검색된 실제 작업 기록만을 근거로 사용자 질문에 답변하고, 사용자가 근거 출처를 확인할 수 있도록 한다.

Client의 기본 창, 답변 요약, 전체 답변·근거 전환은 [검색 중심 소형 창 설계](../compact-search-window.md)를 따른다.
일반 `python -m client [--port 포트]` 실행은 440×112 논리 픽셀의 작은 검색창에서 시작한다. 같은 창의 `관리` 메뉴로 현재 작업·최근 기록·개인정보 보호·조건 검색·문서 가져오기를 열고 `연결 확인`을 수행한다. `검색으로 돌아가기` 또는 Esc로 돌아오면 검색 입력·결과·근거 정렬 상태와 기존 연결을 이어 쓴다.
답변 API 연결 전의 자연어 제출은 `답변 기능 준비 중` 상태를 표시한다. 가상 답변과 근거의 전환은 [Qt 미리보기](../compact-search-window.md#qt-미리보기-실행)에서 확인한다. 실제 Windows 배율·다중 모니터 검증과 답변 API 연결, 메모·우선순위·보호 저장의 동작 합의는 후속 범위다.

2026-11-13 `feat/client-reading-design`은 Client의 안내와 시각 규칙을 정리하고, 전체 답변과 접을 수 있는 근거 영역을 분리한다. 근거 읽기 영역에서는 관련 본문과 출처 정보를 전환한다. 근거 선택으로 답변의 읽던 위치를 바꾸지 않고 기존 정렬·원문 복사를 유지한다. 자연어·조건 검색 API가 준비 중인 일반 실행에서는 최근 기록·문서 가져오기를 안내한다. [읽기 UI 단계의 범위·검증·완료조건](../compact-search-window.md#client-읽기-ui-단계-2026-11-13)을 따르며, 아래 실제 RAG 통합 체크는 유지한다.
