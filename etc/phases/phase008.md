# Phase 8 - 웹페이지 본문 수집

## 목표
URL과 제목뿐 아니라 사용자가 실제로 본 웹페이지의 검색 가능한 텍스트를 확보한다.

## Browser
- [ ] 페이지 텍스트 추출
- [ ] 불필요한 UI 텍스트 최소화
- [ ] 페이지 변경 시 본문 갱신
- [ ] 텍스트 크기 제한
- [ ] 차단 URL에서 본문 수집 금지

## Backend
- [ ] 수신한 웹 텍스트 정리
- [ ] 동일 페이지 중복 텍스트 제거
- [ ] URL / 제목 / 본문 연결
- [ ] 원본 작업 기록과 연결

## Tests
- [ ] 일반 기사 페이지
- [ ] 문서형 페이지
- [ ] SPA 페이지 전환
- [ ] 동일 페이지 재방문
- [ ] 매우 긴 페이지
- [ ] 차단 사이트 본문 미수집

## 완료 조건
- [ ] 웹페이지 내용이 실제 URL과 연결되어 저장된다.
- [ ] 같은 페이지의 불필요한 중복 내용이 최소화된다.
- [ ] 차단 URL의 본문은 저장되지 않는다.
